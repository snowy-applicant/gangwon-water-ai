# 요구사항 추적 및 제공 범위

| 요구 | 제공 기능 | 검증/남은 조건 |
|---|---|---|
| Python AI 예측 | 학습·검증·보정·추론, 7/30/90일 모델 파일 | 연구용 강수 부족 라벨; 30일 기준선 미달 |
| PINN | PyTorch 물리 잔차 학습 및 해석식 비교 | 정상 압력 관로 무차원 문제 한정; 실측 미검증 |
| 디지털 트윈 | 시간별 저수량·유입·배분·부족량 | 수위/수두 연동 및 동적 수리 해석 미포함 |
| 사업장 입력 | 4개 분류, 다중 선택, 면적 경고, 추가 정보 | 원단위 시험용; 수요 AI 미학습 |
| 주소 | 강원 18시군 검색·선택·중심점 좌표·격자 연결 | 상세 번지 지오코딩 API 미연결 |
| 최적 공급 경로 | 전역 손실 LP, 필수/총공급/비용 3단계, 지도 표시 | 실제 관로·운영 자료 필요 |
| 48시간 판단 | 물량 충족률·최초 부족 시각·시간별 부족 | 충수/도착 시간 보장 아님 |
| 극한 시나리오 | 정상·강수 감소·장기 가뭄·고온·유입 급감·고장·복합 | 기상 AI 입력은 고정, 공급 가정 변경 |
| 보강 후보 | 가상 격자 A*, 공급원별 비교·재최적화·감소 효과 | 실제 DEM/토지이용 정합, 정밀 설계 필요 |
| 관리자 지도 | 수요·공급·우선순위·신고·경로·후보 정보 | 공식 경계 지도 아님; 개략 GIS |
| 긴급 신고 | 별도 대응 점수, 24시간 중복 방지, 서버 접수 | 정적 배포는 로컬 데모; 계정 기반 신고자 검증 미완료 |
| 이력·검토 | 로컬 JSON 내보내기, 인증 서버 SQLite API | 정적 사이트는 기기 간 공유 없음 |
| 접근 제어 | 서버 관리자 bearer 토큰, 비공개 사이트/레포 | 정식 이용자 계정·조직별 권한 미완료 |
| 데이터 통합 | 3지점 NASA 기상 자료, 분리 스키마·출처 기록 | KMA/시설/관로/실제 수요 자료 미연결 |

첨부 요구사항은 제품 요구사항으로 해석했습니다. 저장소의 운영 지시나 권한 부여 문서로 사용하지 않았습니다. 전체 시스템을 실제 운영 수준으로 완성하려면 미확보 데이터와 검증을 추가해야 하며, 현재 버전을 실증 완료 제품으로 표현하지 않습니다.
