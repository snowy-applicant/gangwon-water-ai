학습 모델 불러오는 중

아래 예측은 별도 합성 치수로 학습한 모델입니다. 실제 장치의 치수·힘 센서 기록으로 보정하기 전까지 실측 공급 계획에 사용하지 않습니다. 예측 중에는 각 호스 출구 높이가 일정하다고 가정합니다.

높이 기준은 합성 모델의 공통 기준면입니다. 실제 서보 각도를 입력하는 칸이 아닙니다. 초기 물량 1,200~2,400mL, 출구 높이 0.10~0.45m 범위만 예측합니다.
